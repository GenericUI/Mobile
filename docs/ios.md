# iOS Native Backend (`:mobile` `iosMain` / `BackendTarget.IOS`)

> **Module Guide**: [**`:mobile` (`../README.md`)**](../README.md) | **Related**: [`../../docs/apple.md`](../../docs/apple.md) · [`../../docs/ipados.md`](../../docs/ipados.md) · [`common.md`](common.md)

## Overview
The **iPhone iOS** backend (`iosArm64`, `iosSimulatorArm64`; `UIDeviceFamily = 1`) resides inside `iosMain` (`ios/*`) of `:mobile`, built atop `:common`, `:system`, [`:apple`](../../docs/apple.md), and `:mobile` `commonMain`, using Kotlin/Native Objective-C interop against UIKit (`UIApplication`, `UIViewController`, `UINavigationBar`, `UIView`, `UIControl`, `UIScrollView`), **Metal**, **MoltenVK**, and **CoreGraphics**.

> For multi-window iPad support (`BackendTarget.IPadOS`, `UIWindowScene`, Stage Manager, `UIMenuSystem.mainSystem`, and trackpad/keyboard integration), see [**`docs/ipados.md`**](../../docs/ipados.md).

## Single-`commonMain` Architecture & `IosLauncher`

`GenericUiGenerateLaunchersTask` generates `iosMain` entry helpers invoking `IosLauncher`:

```kotlin
// Auto-generated by GenericUiGenerateLaunchersTask
fun MainViewController() = com.nexustools.genericui.ios.IosLauncher.createRootViewController(GeneratedAppDescriptor.create())

fun main(args: Array<String>) {
    val descriptor = GeneratedAppDescriptor.create()
    GenericUI.defaultThemeConfig = descriptor.themeConfig
    com.nexustools.genericui.ios.IosLauncher.launch(args, descriptor)
}
```

When `styles { globalStyleSheet = "..." }` is set, startup attaches the precompiled `PrecompiledStyleSheet` via `app.addStyleSheet(...)`.

## 60+Hz Hardware `backdrop-filter` (`UikitBackdropBlurController`)

- Implemented in [`UikitBackdropBlurController`](../src/iosMain/kotlin/com/nexustools/genericui/ios/UikitBackdropBlurController.kt) and shared by `IosStyledContainerImpl` (`StyledContainer`) and `IosStyledButtonImpl` (`StyledButton`) across both **`IOS`** and **`IPadOS`** (`TextBubble` strips `backdropFilter` via `withoutBackdropFilter()`).
- Layers a hardware Metal-backed **`UIVisualEffectView`** (`CABackdropLayer`) using a paused `UIViewPropertyAnimator` (`fractionComplete`) for continuous CSS blur-radius interpolation plus a composited `tintOverlayView` for color/brightness/saturation adjustments while keeping `hostView.backgroundColor = UIColor.clearColor`.

## `ServiceWorkerExtension.isSupported == false` (Zero Simulation)

- On both **`IOS`** and **`IPadOS`**, `AppleMobileServiceWorkerRuntime` reports **`ServiceWorkerExtension.isSupported = false`** and **`isAutostartSupported = false`**.
- `ServiceWorkerExtensionContributor` skips `@MainServiceWorker` code generation and provider installation for `IOS` / `IPadOS`, guaranteeing `@MainServiceWorker` classes are never instantiated and **zero fake background worker simulation** runs under UIKit.

## Native UIKit Control Rendering, Tinting, & Style Restraints

1. **`BootstrapType.NONE` Default**: `IosBaseNativeImpl` renders 100% unmodified UIKit system controls (`UIButton`, `UITextField`, `UISwitch`, `UISlider`, `UISegmentedControl`) matching the active `UITraitCollection` (`ThemeMode.AUTO`).
2. **`BootstrapType != NONE`**: Tints controls via `UIButton.Configuration` / `tintColor` + `IosControlTintRenderUtil` using `ThemeConfig`, drawing contrasting labels on top.
3. **Typography vs. Aesthetic Style Restraints**: Text elements honor typography/color; standard controls/containers ignore aesthetic CSS properties (tint via `BootstrapType` only); `StyledContainer` / `StyledButton` / `:extensions:ui:alien` honor full `ComponentStyle` chrome including `backdropFilter`.
4. **Strict User CSS Class Isolation**: `styleSnapshot.customClasses` never mixes with `ComponentBootstrap` enums.

## Window Chrome & Shared `:apple` `NSBundle` Resources

- **Optional Top Navbar (`IosWindowImpl`)**: `TitleCapabilities` sets `isTitleBarRequired = false`, `titleBarRendersAsNavbar = true`, `menuBarRendersAsNavbar = true`, and `menuBarMergesIntoTitleNavbar = true`, omitting top bars completely unless `TitleBar` or `MenuBar` is configured.
- **Resources & OS Foundation**: Uses `:apple`'s [`AppleResourceResolverNativeImpl`](../../apple/src/appleMain/kotlin/com/nexustools/genericui/apple/AppleResourceResolverNativeImpl.kt) (`NSBundle.mainBundle` + `Resources.activeTable`), `AppleFileSystemBase`, `AppleDatabaseNativeImpl`, `AppleNetworkMonitorNativeImpl`, and `ApplePreferenceStoreNativeImpl`.
